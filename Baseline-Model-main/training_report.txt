====================================================================
STEP 6 : FEATURE USAGE ANALYSIS
====================================================================
The rule-based model uses only 4 of the 10 features:
  USED    : meanSNR, meanRSSI, PLR, CRC
  IGNORED : varRSSI, varSNR, CFO, SF, CR, link_lost
(link_lost triggers a deterministic fallback, not a threshold rule)

This is the fundamental limitation: fixed rules cannot combine
features non-linearly. The Random Forest uses all 10 features
and captures interactions between them (e.g., low SNR + high
variance + low CRC -> fading, not jamming).
